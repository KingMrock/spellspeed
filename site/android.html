How to install

DuelingBook in your pocket.

The Spellspeed app is DuelingBook with Spellspeed built in: buttons sized for a finger, a replay timeline you slide with your thumb, and DuelingBook links that open straight in the app.

APK coming soon Android 8+ How to install

Not on Google Play yet, so Android asks you to allow the install. The steps below take about a minute.

Four steps, once

About a minute, the first time only.

  1. Download the APK on your phone

    Tap Download APK above in Chrome (or your usual browser). If it warns that the file may be harmful, tap Download anyway: it says that about every app from outside Google Play.

  2. Open it and allow the install

    Tap the finished download. Android asks whether Chrome may install unknown apps: tap Settings, switch on Allow from this source, then go back.

    You can switch it off again afterwards; Spellspeed stays installed.

  3. Install

    Tap Install. If Play Protect says the developer is unknown, tap More details, then Install anyway. If it offers to scan the app, let it.

  4. Open Spellspeed and log in

    Log in to DuelingBook as usual. The app keeps its own login, separate from your browser. A few seconds after the first start, it offers to open DuelingBook links: tap Allow and tick both duelingbook.com addresses, so replay links from Discord open in the app.

Updates and safety

How do I update?

Download the new APK from this page and install it over the old one. Your login and settings stay. New versions are announced on Discord and on X (@spellspeedapp).

How do I know the file is genuine?

Download it only from spellspeed.com or our GitHub releases. Every version is signed with the same key, so Android refuses to install a modified copy over your app. Each release lists its SHA-256 checksum:

Checksum published with the first release.

What does the app access?

Only DuelingBook. It has no tracking or analytics and sends nothing to us. See the privacy policy.

iPhone?

Not yet. Apple does not allow apps from outside the App Store on most iPhones.
