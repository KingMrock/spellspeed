# Spellspeed for DuelingBook — 0.9.1-beta

An unofficial, fan-made browser extension for [DuelingBook](https://www.duelingbook.com/) that makes it quicker and
easier on the eyes, without changing how the game works. Every action still goes through DuelingBook's own duel
commands; Spellspeed only makes them faster to reach. Every feature can be switched off on its own from the toolbar
button, which brings back DuelingBook's original behaviour.

Install: [Chrome Web Store](https://chromewebstore.google.com/detail/fcaoibhakcgpbjickjgpdpdpnfdikdnn) (Chrome, Edge,
Brave, Opera). To load this folder instead: `chrome://extensions` → **Developer mode** → **Load unpacked** → this
folder, then reload DuelingBook.

## Play faster
- Drag and drop cards to summon, set, attack, send to the GY, banish or return them to the Deck, even while animations
  play. A position wheel, or Direct mode with Shift / Ctrl / Alt for the position.
- Right-click any card for a clean action menu, or keep DuelingBook's hover menu.
- Shortcut keys you can remap, a quick chat bar, and mill or banish from the top of the Deck in one step.
- Right-click a phase to ask "end of phase?" or "can I go to …?" in the chat.

## See more at once
- Fan and Grid views for the Deck, Extra Deck, GY and banished cards, with search and sorting.
- A replay timeline you can scrub back and forth, turn marks, step keys, 1×/2×/4×, and Record video.
- Action history for both players, and duel chat names in each player's colour.
- Find a card: look up any card by name or by words from its text, during a duel.

## Build decks better
- Real-time search with more results at once, keyword search with ✱, several categories at once and exclusions,
  Genesis points, search history and undo.
- Card text links: click a description in a card's text to search exactly that; hover a named card to preview it.
- Access, Starters and Ideas (beta): which cards can reach a card, and which one- and two-card lines start it.
- Summon Lab (beta): pick monsters and see which Fusion, Synchro, Xyz and Link Monsters they can make.
- Describe (beta): search cards in plain words ("revive fire monster", "level 4 or lower tuner").
- Opening odds, and Solo practice with a chosen opening hand.

## Make it yours
- Themes (Night, Abyss, Ember…) or DuelingBook's own Classic look; animations and sounds with their own volume.

## Privacy
Spellspeed runs only on duelingbook.com. It stores your settings in your browser, has no server and collects no data.
See `privacy.html`.

## New in 0.9.1-beta
- Classic look: the hover menu in DuelingBook's card viewers stays open reliably; a long menu keeps its full size;
  right-click outside the cards closes a viewer; text boxes and phase buttons look like DuelingBook's.
- Starters and Ideas: a card that can add or Special Summon counts for both; a card sent to the GY counts only when it
  does something there.
